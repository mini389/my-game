# 별 줍기

떨어지는 별을 받고 운석을 피하는 간단한 모바일 게임입니다. HTML5 캔버스로 만든 PWA라서 휴대폰 브라우저에서 바로 실행되고, 홈 화면에 앱처럼 설치할 수도 있습니다.

## 게임 방법
- 화면을 좌우로 끌어서 유리병을 움직입니다 (PC에서는 마우스 또는 ← → 키).
- ★ 별을 받으면 점수가 오릅니다. 연속으로 받으면 콤보가 쌓여 점수가 커집니다.
- ● 운석에 맞으면 목숨이 하나 줄어듭니다. 목숨 3개를 다 잃으면 끝.
- ♥ 하트를 받으면 목숨 +1 (최대 5개).
- 시간이 지날수록 더 빠르고 많이 떨어집니다. 최고 기록은 기기에 저장됩니다.

## 실행
```bash
python3 -m http.server 8000
# 휴대폰과 같은 Wi‑Fi에서 http://<PC IP>:8000 접속
```

## 휴대폰에 앱으로 설치
GitHub Pages(Settings → Pages → 이 브랜치 / root)로 배포한 뒤 휴대폰에서 주소를 엽니다.
- Android Chrome: 메뉴 → **홈 화면에 추가 / 앱 설치**
- iPhone Safari: 공유 버튼 → **홈 화면에 추가**

설치하면 전체 화면으로 실행되고 오프라인에서도 플레이할 수 있습니다.

## 파일
- `index.html` — 게임 전체 (캔버스, 로직, UI)
- `manifest.webmanifest`, `sw.js` — 앱 설치·오프라인 지원
- `icon.svg`, `icon-*.png` — 앱 아이콘
